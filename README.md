# Book Data Files

[⤓ 下载 BookDataFiles.zip](https://github.com/CYJB/calibre_plugin_data_files/releases/download/latest/BookDataFiles.zip)

在 calibre 的**书籍详情面板**里，把当前这本书 `data` 目录下的文件**一行一个**列出来，
点击文件名直接用系统默认程序打开。

面板里大致长这样（默认只显示大小，可以配置显示修改时间）：

```
书名       某本书
作者       ……
数据文件   a.pdf           4 KB
           sub/说明.txt     12 B
           封面原图.jpg     2 MB
```

## 兼容性

在 **calibre 9.17.0**（Windows 10 22H2，portable 安装）上验证通过。最低声明版本 6.0，
更早的版本未逐一验证。

## 安装

1. calibre — 首选项 — [高级选项] 插件 — 从文件加载插件（右下角） — 选 `BookDataFiles.zip`
2. 重启 calibre

不用在「搜索元数据」里勾选任何东西；装好即生效。

## 使用

calibre 的约定是：书库里每本书的目录（`书库/作者/书名 (id)/`）下可以有一个 `data`
子目录，专门放附加的数据文件。放文件有两种办法：

* 直接把文件**拖到书籍详情面板上**，弹出菜单里选「添加为数据文件」；
* 或者点详情面板「路径」那一行的「数据文件」链接打开该目录，把文件拷进去。

然后切换到别的书再切回来，或者用插件带的操作「刷新书籍详情」（默认在「插件」菜单里，
可自行拖到工具栏 / 加快捷键），列表就会更新。点击文件名即打开。

子目录会递归列出（显示为 `sub/xxx.txt`）；隐藏文件（`.` 开头）不显示；超过 300 个
文件时只列前 300 个。

每行右侧的额外信息默认只显示大小（例如 `1.4 KB`、`1.1 MB`）。

## 配置

首选项 — [高级选项] 插件 — Book Data Files — **自定义插件**：

* **只显示这些扩展名的文件**：逗号分隔，`pdf, jpg, png`；写 `*.PDF`、`.jpg` 也能识别。
  留空表示显示全部（默认）。
* **显示文件大小**：默认勾选。
* **显示修改时间**：默认不勾选；勾上后每行变成 `1.4 KB · 2026-10-11 20:15`。
* 两个都取消勾选时，每行只显示文件名（仍然可以点击打开）。

过滤只影响面板显示，不会移动/删除 `data` 目录里的文件；没有扩展名的文件在设置了
过滤后不显示。有文件被过滤掉时，面板末尾会提示「N 个文件因文件类型设置未显示」，
避免误以为文件丢了。

配置保存在 calibre 配置目录的 `plugins/book_data_files.json`，例如：

```json
{"extensions": "pdf, jpg", "show_size": true, "show_mtime": false}
```

也可以直接改这个文件（改完切一下书即可生效）。

## 已知限制

* 只对**书库里的书**生效；设备上的书不显示。
* 面板不会监视文件变化，加/删文件后需要切换书籍或执行「刷新书籍详情」。
* `.exe/.bat/.cmd/.ps1/.py` 这类可执行文件点击后不会打开（calibre 的安全限制）。
